# 🥁 Drum Kit

An interactive **Drum Kit Web Application** that allows users to play different drum sounds using both **mouse clicks and keyboard inputs**. The application provides real-time audio feedback with smooth button animations for an engaging user experience.

This project demonstrates the use of **JavaScript DOM manipulation, event handling, and audio integration** to create an interactive web application.

## Features

- Interactive drum buttons with mouse click support
- Keyboard controls for playing drum sounds
- Multiple drum sound effects:
  - Tom drums
  - Crash cymbal
  - Kick bass
  - Snare drum
- Button animations for visual feedback
- Responsive design across different screen sizes
- Lightweight frontend application

---

## Controls

You can play the drum kit using the following keys:

| Keyboard Key | Instrument |
|--------------|------------|
| W | Tom 1 |
| A | Tom 2 |
| S | Tom 3 |
| D | Tom 4 |
| J | Crash |
| K | Kick Bass |
| L | Snare |

You can also click the buttons directly using your mouse.

## Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/Iyazuddin/Drum_Kit.git
```

### 2. Navigate to the project directory

```bash
cd Drum_Kit
```

### 3. Run the application

Open `index.html` directly in your browser.

For better development experience, use the **Live Server extension** in VS Code.
